# Data model

Catalogue tables, migrations, provenance rules, and idempotent seed data are
deferred to Work Package 3. ADR-002 fixes MySQL 8.4 LTS, InnoDB, Prisma, DECIMAL
measurements, and least-privilege access as the implementation constraints.

The nine product decisions in section 19 of the canonical implementation plan
must be resolved, or its defaults explicitly adopted, before that package.
