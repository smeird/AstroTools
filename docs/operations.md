# Operations

Apache2, systemd, MySQL backup and restore, release, rollback, monitoring, and
alerting procedures arrive in Work Package 9. ADR-001 already fixes Apache2 as
the only public endpoint and the standalone Node service as loopback-only.

No example configuration in this repository may contain a real domain,
certificate path, credential, or host-specific secret. Deploying Apache
configuration always requires separate operational approval.
