# Astrotools target illustrations

The six SVG files in this directory are original, deterministic Astrotools
illustrations created for the target-framing simulator. They are deliberately
recognisable visual guides, not calibrated sky-survey imagery and not evidence
of surface brightness, orientation precision, or photographic appearance.

The illustrations are licensed under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
Credit: `Astrotools target illustration, CC BY 4.0`.

Angular dimensions, orientation references, provenance URLs, and verification
dates are stored separately in the target catalogue. The simulator uses those
catalogue measurements—not the SVG view boxes—for all proportional geometry.
